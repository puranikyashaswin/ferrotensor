About · Ferrotensor {{ft_version}}

Fine-tuning in Rust, through Vulkan, Metal or DX12

Ferrotensor is an open-source machine learning framework written in Rust. It fine-tunes language models from one codebase through wgpu and hand-written WGSL kernels, which run through Vulkan, Metal or DX12. There is no CUDA toolchain to install. It has been tested on an NVIDIA A10G, an Apple M2 and software Vulkan in CI; other GPUs are untested, and reports are welcome.

Why it exists

Most training tools are built for CUDA first. A laptop, a consumer card or an integrated GPU is often left out, and the code between the Python API and the GPU is hard to read.

Ferrotensor takes the other route. The same kernels run through Metal on a Mac and through Vulkan or DX12 on Windows and Linux, and cargo build is the whole toolchain. The tests check op gradients against finite differences on the CPU, GPU results against a CPU device, and the LoRA loss and gradients against PyTorch autograd, so a result on one GPU can be compared with a result on another.

What is measured so far

Every number on this site comes from a run with its commands, machine and commit written down.

  • 1.7BSmolLM2-1.7B fine-tuned with LoRA on one NVIDIA A10G (24 GB): 8,222 MiB of GPU memory in 0.7, 5,245 MiB with --checkpoint-blocks.
  • 0.005Largest gap in held-out loss against PyTorch + PEFT on CUDA, same GPU and recipe; Ferrotensor is slower per step.
  • M2SmolLM2-135M fine-tuned with LoRA on an Apple M2 (8 GB) with a 0.4 build.

The full tables are in the LoRA walkthrough and the benchmarks. What it cannot do yet is listed on the home page, including where it is slower than PyTorch.

Where it is going

The goal is training that goes wherever a GPU is: AMD and Intel cards, a browser tab through WebGPU, and edge boards such as NVIDIA Jetson, with the training data staying on the device. The steps, and which of them are already measured, are in the roadmap.

Who builds it

I'm Puranik Yashaswin Sharma, a computer science student at Woxsen University in Hyderabad, India. I design, write and maintain Ferrotensor: the kernels, the autograd, the LoRA trainer, the Python bindings and this site. The code is on GitHub and released on crates.io and PyPI.

It is a young project. Reports from GPUs I do not own help the most: testing on your GPU takes one command.
